
# Car Insurance Management System

## Overview
A full-stack Car Insurance Management System built using Java Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features
- Customer & Vehicle Registration
- Insurance Policy Management
- MySQL Database Integration
- REST APIs using Spring Boot
- DTO, Mapper, Repository, Service Architecture
- Form Validation using Jakarta Validation
- Responsive Glassmorphism UI
- Frontend–Backend Integration

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Gradle

### Frontend
- HTML5
- CSS3
- JavaScript

## Architecture

Frontend (HTML/CSS/JS)
→ REST APIs
→ Spring Boot Controllers
→ Service Layer
→ Repository Layer
→ MySQL Database
